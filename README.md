# UniMate 🎓  
**Year 2 – Semester 2 IT Project**

UniMate is a **centralized digital platform for university students**, designed to simplify and enhance everyday university life.  
The system integrates multiple essential student services into **one unified ecosystem**, reducing fragmentation and improving accessibility.

This project was successfully completed as part of the **Year 2 – Semester 2 IT Project module**, and it achieved an **A Grade (A Pass)**.

---

## 🌐 Live Deployment
The system is deployed and accessible at:

👉 https://unimate-frontend.vercel.app

---

## 🎯 Target Users
UniMate was built **for university students**, with additional role-based access for:
- Administrators
- Service providers (e.g., accommodation owners, food vendors, hiring managers)

The platform focuses on solving real student problems by providing trusted, student-specific services in one place.

---

## 🧩 System Overview
UniMate is composed of **five independent yet integrated subsystems**, each developed by a dedicated team member.  
Together, they form a **centralized hub** for students.

### Key Services
- 🏠 **Accommodation Finder**
- 💼 **Student Job Portal**
- 🍔 **Food Ordering System**
- 📚 **Study Material Sharing Hub**
- 🛒 **Student Marketplace**

All subsystems are integrated under a **single student identity**, allowing seamless access across services.

---

## ✨ Core Features
- Role-based authentication & authorization
